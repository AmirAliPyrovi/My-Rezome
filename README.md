## 🌐 Overview | معرفی پروژه

**English:**

This is a responsive, bilingual (Persian/English) portfolio website built with HTML, CSS, and JavaScript. It focuses on frontend development and showcases my projects, technical skills, and experience with backend technologies.

**فارسی:**

این پروژه یک وب‌سایت شخصی و واکنش‌گرا با پشتیبانی از دو زبان فارسی و انگلیسی است که با استفاده از HTML، CSS و JavaScript توسعه داده شده است. تمرکز اصلی آن بر توسعه فرانت‌اند، نمایش پروژه‌ها، مهارت‌های فنی و آشنایی من با فناوری‌های بک‌اند است.

---

## ✨ Features | امکانات

- Responsive Design — طراحی واکنش‌گرا برای موبایل و دسکتاپ
- Persian / English Language Switch — تغییر زبان فارسی و انگلیسی
- Dark Theme — قالب تیره با جزئیات آبی
- Animated Page Loader — صفحه بارگذاری انیمیشنی
- Typing Animation — افکت تایپ خودکار متن
- Mobile Navigation — منوی مخصوص موبایل
- Scroll Progress Bar — نوار نمایش میزان اسکرول
- Scroll Reveal Animations — انیمیشن نمایش عناصر هنگام اسکرول
- Animated Skill Indicators — نمایش متحرک مهارت‌ها
- Interactive Project Cards — کارت‌های تعاملی پروژه‌ها
- Floating Social Links — دسترسی سریع به شبکه‌های اجتماعی
- Downloadable Resume — امکان دریافت رزومه
- Back to Top Button — دکمه بازگشت به بالای صفحه
